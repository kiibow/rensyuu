## ポイント
- 良いプロンプトを書くだけでは終わらない。
- 既製のスタイル・OSSプロジェクト・ワークフロー（多くが無料）を使うとクオリティが大きく上がる。
- 一部は Claude Code / Codex にリンクを渡して「インストールして」と頼むだけで使える。
- 他はアニメーションのソースコード・使用プロンプト・サンプル付き。
- まずは **1と2** から見るのがおすすめ（未体験のスタイル発見に良い）。
