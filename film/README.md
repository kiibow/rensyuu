# AI動画は、なぜ毎回同じ見た目？（30秒の解説動画）

「Explainer Motion Studio Prompt」（[PROMPT.md](PROMPT.md)）を、そのまま1本ぶん実行したもの。

- 一文のアイデア：動画の差はプロンプトより、AIが自分のコマを見て直す工程で決まる
- 流れ：問い → 仕組み（draw(t)） → 実例（書く→描画→見る→直す を3周） → 「見る」を外すと元に戻る → まとめ

## 成果物（out/）

| ファイル | 内容 |
|---|---|
| `master_16x9.mp4` | 1920×1080 / 60fps / 30秒 / H.264 crf16 yuv420p + AAC |
| `cut_9x16.mp4` | 1080×1920（図を縦積みに組み替え） |
| `cut_1x1.mp4` | 1080×1080 |
| `master_16x9_reduced_motion.mp4` | 動きを減らした版（移動は瞬時の切替、同じ順序） |
| `captions.srt` | 見出しと効果音の字幕（見出しは映像にも焼き込み済み） |
| `contact.png` | 完成した映像から1拍ごとに切り出した60コマ |

制作の記録：[DECISIONS.md](DECISIONS.md)（判断の1行ログ）、[SOURCES.md](SOURCES.md)（数字の出典）、[directions.html](directions.html)（3案の比較）、`review/`（修正前後の比較画像）。

## 作り直す

```sh
fonts/get-fonts.sh   # Noto Sans JP / JetBrains Mono（OFL）を取得
./build.sh           # 音 → 4本の映像 → ラウドネス調整・合成
python3 gen_srt.py   # 字幕を作り直す
```

必要なもの：Node 22、Playwright（Chromium）、ffmpeg。`src/film.js` の `TIMELINE` に、すべての拍・動き・効果音がまとまっている。

## 実際に確かめたこと（ここに書いたものだけ）

- 同じコマ（16:9、t=13.4秒）を2回描いて、PNG の md5 が一致した。
- 4本とも、解像度と30.000秒の長さを ffprobe で確認した。
- マスターの音量：-15.9 LUFS（integrated）、true peak -1.5 dBTP。
- 音だけを解析：効果音とモチーフの立ち上がり20か所は、TIMELINE の時刻から±0.01秒以内。残り1か所（5.0秒の低いドスン）は、低域が +10.8 dB 上がることで確認した。「見る」を外した区間（24〜25秒）は、前後より約12 dB 小さい。
- 音なしで、完成映像の60コマ（contact.png）を順に見た。
- 9:16 の最後のコマを390px幅に縮めて、見出し2行とラベルが読めることを確認した。
- 色のコントラスト（WCAG）：本文 14.8:1、補助テキスト 4.8:1、アクセント 5.1:1。いずれも背景に対する値。
- デザインレビュー担当のサブエージェントの指摘8点（コントラスト不足、不正確な言い方、呼び方の統一、縦型の文字サイズ、マーカーの見えにくさなど）を直した。その修正前後の比較画像を `review/` に置いた。

## 確かめていないこと

- 耳で実際に聞くことはしていない（音は数値で解析しただけ）。
- 減らした版、9:16、1:1 は、静止画のチェックとファイルの確認だけで、全コマは見ていない。
- 「Anthropicデザイナーのプロンプト」の出どころ：画像の注記どおり、@0xCarnagee が Meaghan Choi 氏の講演内容をまとめたもの。本人が書いたり、内容を保証したりしたものではない。
